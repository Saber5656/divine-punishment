## 実操作に基づく改訂（2026-09-13）

A の通常歩行と重力による実測は32.368秒で帳場へ到達。B はEで梯子/梁、Shiftで梁を下りて屋根上を歩き、37.879秒で母屋上空へ到達した。無敵化・障害物除去・途中warpは使っていない。

水際は、泳ぎの高さを固定する領域を上り坂の手前で終える。後方の坂で泳ぎが止まる失敗を先に再現し、Z=16–20の上陸部分だけ水域西端をX=86.8へ切り欠いた。東水路の残りはX=82–94を維持し、全体で4つの連続WaterVolumeに分割する。南側はX=18から水域に入る。岸の床にも坂の通過穴を設け、平らな床が斜面を塞がないようにした。

観察点は導入、蔵内、蔵1屋根、船の前後、母屋床下の6点。梯子の柱と横桟を表示し、登攀取付を見て判断できるようにした。最終アートは #61 の範囲。

最終地形版の配布ビルドではA 32.275秒、B 37.864秒、C 121.235秒、すべて失敗0。Cは南水路→船底潜行→浮上→後方上陸→床下まで実操作で通過した。床下への坂には低い側へ回り込む足場（X=82–86/Z=13–17）と水平な上端（X=78–79.5、床上面0.8）を追加した。坂はX=84→79.5、root0→1.7。これにより入口手前で立位の足元が揃い、crawlへ安全に遷移する。現行の全座標はsceneのROUTESが正本。

610 tests / 4,806 assertions、地形のfocused 8 tests / 47 assertions成功。自己レビューで水域の切欠きによる乾いた隙間、岸や床下入口の実姿勢遷移、個人パス・秘密値を確認した。NPC・任務・未発見クリア・16分基準・Postの完了を意味しない。

## NPC詳細実装（#171）

300秒は既存RoutineStopの時刻窓（0–180帳場、180–240検分、240–300密談）として実装する。各窓には次の場所までの実移動時間を含める。3分+1分+1分の完全停止に別途移動を加えて5分と称したり、瞬間移動で辻褄を合わせたりはしない。4倍速のnative検証では検分到着213.533秒、桟橋258.667秒。桟橋で警戒を上げた後、20.8秒の実移動（simulation time）で母屋へ戻り、予備護衛が合流した。

帳場の算盤は元の録音を使わず、木の珠の短い打音を決定的に合成した位置音源。SE設定を使い、帳場にいる健在の標的がcount中だけ鳴る。警戒・移動・無力化時は止める。最終サウンドは #82、NPCの最終アートは #61。

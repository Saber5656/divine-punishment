# M5 祭りの夜 — 実装前レイアウト

親 #64、地形 #187、配置 #188、固有機構 #189、通し検証 #190。
正本は `docs/07-campaign-missions.md` M5。これは実装前の設計であり、通行実測ではない。

目的は黒沢帯刀の暗殺と南側入口への脱出。消せない提灯が主体の街で、
群衆へ紛れる・花火の周期を読む・裏の用水路へ潜る、という3つの選択を作る。
座標はX東、Z南、Y上、m単位。通常プレイヤーの中心は歩行面の0.9m上。

A: (12,0,88)→(24,0,80)の群衆導入→(48,0,76)→参道を群衆と北上
→(51,0,33)→神社階段(51,3,25)→参拝する標的の背後。混雑の少ない
時間も屋台角で待てるよう、群衆だけを唯一の安全手段にしない。

B: 西屋根の南端で登攀→屋根列→Z48の横断橋→東屋根→桟敷の屋根。
屋根開口X83–85/Z31–33から、(84,6.9,32)の梁で標的(84,3,32)を狙う。
上方暗殺の既存4m範囲に合わせ、機能側の距離や敵視界を緩めない。
45秒周期のうち3秒の花火では屋根だけV×2、音は全域でマスクする。

C: 裏路地→井戸の縁→Y-3へ降下→(84,-3,13)→用水路→
(84,-3,22.5)の匍匐入口→斜路→桟敷の床開口内(84,1.72,35)。
開口内の小階段(84,1.72,35)→(84,3,38)を登り、東側を回って標的へ。
用水路は浅水床として足音を出し、井戸と桟敷床下以外では地表へ抜けない。
井戸の穴と桟敷下の空間を地面の実衝突から除外し、天井に斜路を貫通させない。

共通退路: 神社または桟敷の実階段→参道の南側→(40,0,84)→開始地点。
地上出口を確保し、梁や一方通行の井戸への戻りを必須にしない。

配置 #188: 同心8・護衛2・標的1、民間人12。詳細仕様の「8+2」を
護衛側10名として扱い、標的を別に数える（一覧表は10+民12表記）。
民間人は既存の5人群衆2組と独立した2名。先頭群衆は安全な導入から
参道へ移り、後続は屋台を巡回する。群衆の既存conceal/disruption条件を維持する。
標的は6分周期で桟敷3分→神社2分→屋台1分。実際の移動時間を含め、
護衛2名が外で待つ参拝窓を30秒確保する。時刻による座標移動は使わない。

段階検証: #187では実PlayerControllerの3経路・段差・開口・帰路を検証。
#188で生きたAI/群衆、#189で花火・鳴子・悲鳴0副目標・checkpointを接続し、
#190で通常時間の書き出し版を通す。20分疾風は設計値のまま保持し、
自動操作の時刻を初見/中級者の実測にしない。後日談は#79、美術は#65。

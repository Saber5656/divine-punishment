# M5 祭りの夜 — 実装前レイアウト

親 #64、地形 #187、配置 #188、固有機構 #189、通し検証 #190。
正本は `docs/07-campaign-missions.md` M5。これは実装前の設計であり、通行実測ではない。

目的は黒沢帯刀の暗殺と南側入口への脱出。消せない提灯が主体の街で、
群衆へ紛れる・花火の周期を読む・裏の用水路へ潜る、という3つの選択を作る。
座標はX東、Z南、Y上、m単位。通常プレイヤーの中心は歩行面の0.9m上。

A: (12,0,88)→(24,0,80)の群衆導入→(48,0,76)→参道を群衆と北上
→(51,0,33)→神社階段(51,3,25)→参拝する標的の背後。混雑の少ない
時間も屋台角で待てるよう、群衆だけを唯一の安全手段にしない。

B: 西屋根の南端で登攀→屋根列→Z48の横断橋→東屋根→桟敷の屋根。
屋根開口X83–85/Z31–33から、(84,6.9,32)の梁で標的(84,3,32)を狙う。
上方暗殺の既存4m範囲に合わせ、機能側の距離や敵視界を緩めない。
45秒周期のうち3秒の花火では屋根だけV×2、音は全域でマスクする。

C: 裏路地→井戸の縁→Y-3へ降下→(84,-3,13)→用水路→
(84,-3,22.5)の匍匐入口→斜路→桟敷の床開口内(84,1.72,35)。
開口内の小階段(84,1.72,35)→(84,3,38)を登り、東側を回って標的へ。
用水路は浅水床として足音を出し、井戸と桟敷床下以外では地表へ抜けない。
井戸の穴と桟敷下の空間を地面の実衝突から除外し、天井に斜路を貫通させない。

共通退路: 神社または桟敷の実階段→参道の南側→(40,0,84)→開始地点。
地上出口を確保し、梁や一方通行の井戸への戻りを必須にしない。

配置 #188: 同心8・護衛2・標的1、民間人12。詳細仕様の「8+2」を
護衛側10名として扱い、標的を別に数える（一覧表は10+民12表記）。
民間人は既存の5人群衆2組と独立した2名。先頭群衆は安全な導入から
参道へ移り、後続は屋台を巡回する。群衆の既存conceal/disruption条件を維持する。
標的は6分周期で桟敷3分→神社2分→屋台1分。実際の移動時間を含め、
護衛2名が外で待つ参拝窓を30秒確保する。時刻による座標移動は使わない。

段階検証: #187では実PlayerControllerの3経路・段差・開口・帰路を検証。
#188で生きたAI/群衆、#189で花火・鳴子・悲鳴0副目標・checkpointを接続し、
#190で通常時間の書き出し版を通す。20分疾風は設計値のまま保持し、
自動操作の時刻を初見/中級者の実測にしない。後日談は#79、美術は#65。

初期衝突検証による修正: 桟敷床下の匍匐出口は小階段の開始点Z35から、
直前の平場Z34.5へ移す。既存プレイヤーの姿勢復元判定で、傾斜の始まりが
しゃがみ姿勢の体へ重なることを確認したため。階段・開口自体は維持する。

実プレイヤーのC経路では、X72を真北へ進むと桟敷西階段の側面Z34.36で
止まった。Z38でX66へ回り、階段を西側から迂回してZ26から井戸へ進む。
階段は地上退路に必要なので、衝突を消さず裏路地の経路を修正する。

C出口の操作検証: 匍匐入口の内側端は外側Z34.5から0.5m内側のZ34.0とする。
従来の1.5mでは斜面上Z33.0に判定が残り、平場へ登ると操作半径0.75mを外れた。
平場Z34.4へ進んでEを押す経路にし、共通プレイヤーの操作半径は変更しない。

退出時の移動判定は着地後の実姿勢でも検証する。外側マーカーY1.72は歩行面
からの高さが余裕ゼロで、着地後の短い移動が床に当たったためY1.74へ上げる。
他の出入口と同じ2cmの床上余裕を設け、床や衝突判定側を変更しない。

追加の着地後検証により、マーカーの高さだけでは不十分と判明した。
停止後の体と床の接触が移動経路判定にだけ障害物として数えられるため、
共通移動判定にも既存の到達点判定と同じ5mmの支持面余裕を適用した。
実際に接地させる単体テストで失敗を再現してから修正し、壁の貫通防止と
水中移動を含む回帰テストを通した。上段の「判定側を変更しない」は
当初の修正案の記録であり、最終実装ではこの小さな依存修正を含む。

床下全体にはY-3.9の受け床を設ける。用水路の細い斜路から横へ外れても、
世界の外へ落ち続ける構造にしない。実レイによる床下支持面テストで欠落を
再現して追加した。地上・桟敷床・屋根の開口と3経路は維持する。

PR192レビュー対応: 外周から床下へ落ちる迂回と受け床の外への落下を防ぐため、
桟敷の基礎を床下Y-3.9から床裏Y1.9まで閉じる。北側X82–86には
Y-1.1より低い用水路開口を残し、その上は梁状の壁で塞ぐ。
西階段の到達面Y2.1は基礎より高く、通常の出入りを維持する。

敵配置188の実装記録: 同心8と標的・護衛2、民間人は5人群衆2組と独立2名。
独立した群衆曲線は閉じ、周回時に入口へ飛び戻らない。民間人の原点は足元
Y-0.9で、プレイヤーの中心Y0.02とは区別する。参拝は実到着後に護衛が
神社外(47,0.02,31)/(55,0.02,31)まで歩いて離れてから30秒を数える。
戦闘や不審状態を行動予定で解除せず、静穏な連続30秒を確認する。
単一の動的な目的地にも、既存PatrolPathが要求する実経路曲線を添え、
桟敷階段→参道→神社階段を示す。範囲を緩めずマップ中央を経路原点にする。

PR193レビュー対応: 神社外の護衛は西側が西、東側が東を向き、参道中央・神社入口・参拝中の標的を視野から外す。祭り専用EscortGuardは移動を行動予定へ任せつつ、標的死亡の一度限りの戦闘反応と気絶から復帰した際の遅延反応を維持する。実AIの全参拝窓と直接暗殺fixtureで確認した。

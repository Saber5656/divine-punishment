# M4 雨の山寺 — 実装前レイアウト

親 #62 / 経路 #178 / 配置 #179 / 固有機構 #180 / 通し検証 #181。
正本は `docs/07-campaign-missions.md` M4 と `docs/04-level-design.md` §4。
本図は実装前の設計。実測値・完成報告ではない。

目的は鉄仙坊の暗殺と、12分後に処刑部隊が向かう座敷牢の遺臣2名の救出。
救出失敗でも主目的を続行できる。入口には雨・軒下の灯り・水音を安全に
試せる場所を置き、正面・高所・救出優先の3経路を初めから分岐させる。

座標はGodotのX/Z平面、Y上向き、m単位。図の上が北（-Z）。表のYは
プレイヤーの通常立ち姿の中心位置で、歩行面は原則0.9m下に置く。
北南100m、東西96m。立入境界は外周に置き、通路上に見えない障害を置かない。

経路A: 開始(12,0,88)→(40,0,84)→石段(40,4,66)→山門(48,4,58)
→中庭(48,4,40)→本堂階段(48,8,32)→鉄仙坊(51,8,22)。読経周期の
向き直りを待つ場所と柱/壁の遮蔽を組にし、タイミングを見て進めるようにする。

経路B: 開始→崖下(18,0,72)→登攀(18,4,70)→墓地(24,4,58)
→宿坊屋根(28,8,48)→屋根橋→本堂屋根の南端(44,11.6,32)→(44,11.6,30)→梁(51,11.9,22)。
最後は専用ClimbEdge/BeamPathで梁へ移る。屋根開口には見た目・衝突双方で穴を設ける。

経路C: 開始→安全な沢入口→東の沢沿い→水車側上陸(88,0,44)
→東壁外の斜路(86.75,0,44)→床下入口(86.75,3.72,32)→匍匐→牢の床開口(74,3.72,32)
→短い内階段(72,5,32)→遺臣の解放。救出後は牢北側の階段で本堂へ。
床下両端に出入口を置き、立ち上がる場所に頭上空間を確保する。

退路は南の導入区画と東の沢下流。救出時には2名が実際に通れる
地上退路（牢→中庭→山門→石段→導入区画）を確保する。護衛NPCを
梁・匍匐・水中に強制せず、プレイヤーの捷径とは独立に通行検証する。

配置計画: 僧兵8名は山門2・中庭2・墓地1・鐘楼1・宿坊1・本堂前1。
鉄仙坊1名と牢番1名を加え計10名。雨の視界補正に僧兵の傘の追加20%を
乗算し、アーチャー等の他職の設定は流用しない。読経は共通時計に同期し、
移動中に座標を書き換えない。鐘の集合もNavigation経由で本堂へ向かわせる。

検証計画: 最初に実PlayerControllerのA/B/C通行、梁/床下の接続、退路、
地上護衛経路を検証。以後NPC・鐘・12分後の実移動・戦闘・checkpointを
段階的に加え、最後に通常時間の輸出ビルドで未発見クリアと救出を測る。
12分の時間経過を加速した単体/機構テストと、実時間の通し検証は区別する。
20分の疾風基準は設計値として保持し、初見/中級者の実測と偽らない。
Postは#79、H3の台詞表示は#81、環境美術は#63との接続を明示する。

実装時の修正: 屋根橋の終点を屋根南端Z32へ合わせ、到達前の天井衝突を避ける。水車側の斜路はX86.75（牢の東壁外）へ移し、通常立位で床下入口まで登れる空間を確保した。牢から本堂への上り階段はZ28、避難用下り階段はZ30から南へ伸ばして交差を避ける。いずれも実衝突テストに基づく地形修正。
沢の上陸斜面では水中状態を維持すると水面の高さに固定されて斜面へ進めなくなるため、上陸口2箇所の泳ぎ判定をX92.8以東へ絞る。通常の沢は残る3領域でX88まで覆い、水路の中心X94を通行経路とする。牢内段差の床開口はX72–75へ広げ、斜路の高い端で床に乗り移れるようにした。
床下出口は段差に体が重ならない平場X74.5に置き、出口で通常姿勢へ戻ってからX74の段差へ進む。
本堂屋根の立位高はY11.6、梁はY11.9に修正。標的中心Y8.02との距離を既存の上方暗殺4m以内に収める。暗殺距離・敵の判定設定は変更しない。

配置実装 #179: 墓地と中庭の2mの隙間に、X32–34 / Z56–60 / 歩行面Y3.1の
実体のある渡り板を追加。NPCは登攀せず墓地・中庭・地上を往復できる。
標的の牢見回りは本堂正面階段→中庭→牢の南側階段を使う。
北側の上り階段は本堂の東壁に突き当たるため、直接の本堂入口としては使わない。
歩行可能領域は実際の箱型衝突から生成し、屋根・水・床下・墓石の上面を除外する。

僧兵8名は36秒の共通周期で最初の4秒間、その場から本堂へ向き直る。
鐘楼の4秒の合図音が窓を知らせ、続く16秒ずつで巡回の往復を行う。
通常の読経音は警戒を増やさない。プレイヤーが使う一度限りの集合鐘は#180。
雨の視界80%と傘の追加80%を重ね、僧兵の通常視界15mは9.6mになる。
鉄仙坊は720秒を過ぎた最初の更新から見回りへ移り、実際に歩いて牢へ到着する。
共有のRoutineStopは終了時刻を含むため、720秒ちょうどは稽古の最後の瞬間になる。
戦闘・知覚・気絶の処理は巡回時計の同期中も保持する。開始し直すと時計・配置・雨を初期化する。

配置段階の限界: 使用モデルは既存の仮モデル。傘・僧兵・薙刀の専用美術は#63。
救出、処刑、集合鐘、HP8/攻撃2、チェックポイントへの世界状態保存は#180、
キャンペーン選択・通常時間の暗殺/救出通し確認は#181で扱う。

固有機構実装 #180: `temple_mission.tscn` をM4定義へ接続した。
鐘楼(26,4.02,54)でEを押すと、一度だけ警戒+1と60秒の本堂集合を行う。
全員が異なる集合点へ実際に歩き、鐘の終了後は通常の仕事へ戻る。
720秒以降は中庭の2名が牢へ向かい、到着して初めて未解放の遺臣を斬る。
集合鐘はこの移動も一時中断する。救出失敗後も標的暗殺と脱出は続行できる。

遺臣は牢の(76,5.02,35)/(82,5.02,35)付近でEにより一人ずつ解放する。
救出者は地上退路を歩き、開始地点(12,0.02,88)へ2名とも生還すると副目標+5。
標的撃破後は開始地点でEを押して脱出する。遺臣を待つ間に自動終了はしない。
鉄仙坊はHP8/攻撃2、受け流し後1.2秒だけ通常斬撃が通る。暗殺は既存の判定を使う。

チェックポイントは開始時、中庭(38,4.02,62)、牢(72,5.02,28)、暗殺後。
再挑戦時には時計・鐘・敵10名・遺臣2名・目標と加点をまとめて復元する。
H3には初回クリア時の救出成否を保存して反映し、後の最高点更新から独立させる。

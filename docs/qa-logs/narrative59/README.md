# Narrative text design and acceptance (#59)

Design decided before implementation: reuse the existing Noto Serif Japanese typography, ink/ivory palette and input-free HUD. Monologue is a single vertical column near the right edge, ending in the lower third; its height adapts to text length and viewport so the entire sentence remains legible. Last words use a separate bottom-centered horizontal line with a dark translucent backing. Both last four seconds, fading during the final half-second, without sound or a new confirmation. Pause freezes their timer. Disabling monologue clears the current column and suppresses subsequent requests; it does not suppress target dialogue. Result comments appear after the non-target kill total in the existing scroll.

This is a native Godot game implementing the already approved narrative/HUD specification, outside the Web/mobile Product Design policy scope. No new design plugin workflow is claimed. A literal long vertical sentence wholly inside the bottom third would require tiny glyphs, so the column ends there while extending upward. Final captures will verify the chosen layout.

M2/M3/M4/M6/M7/M10 dialogue follows the canonical narrative; M5/M8 last words and unspecified inner lines are concise original supplements consistent with their roles. M6 exposes an assassination hesitation clip hook for all four approaches; it does not change hit timing or state ownership. Stage-specific cinematics remain in their existing Issues.

Final-objective transition preserves the existing victory world freeze while only the dialogue timer continues; then it opens results. Retry/abandon invalidates the old scene-owned transition. Ordinary in-mission pause still freezes dialogue.
